Trust, rendered in Certified Green.

A single desaturated green carries verification and action across a warm-cream / deep-teal-ink system. The mark is a rub el hizb octagram — Islamic geometric heritage, never a religious symbol used as UI decoration.

01 · Symbol

The Mark — rub el hizb octagram

Two interlocked squares on a 64 px grid: one axis-aligned, one rotated 45°. Single geometry source: src/lib/components/site/mark.svelte. Recolor via currentColor — never redraw.

outline

Logo / header / footer. stroke-width 4.

solid

Seals, favicons, filled states. fill = currentColor.

pattern

.pattern-girih tiling texture, opacity --pattern-opacity 0.04 light / 0.06 dark.

Whitelist for pattern texture: hero containers, footer, sidebar brand strip, login/register, 404. ❗ Cultural red lines (§8 plan): crescent and other religious symbols are banned as UI decoration; certification seals must never imitate JAKIM / MUI / HFA official marks.

04 · Shape & depth

Radii tighten inward; shadows are warm-tinted

Radius

6 sm · 8 md (controls) · 10 lg (icon/tile) · 14 xl (cards, popovers)

Shadow

sm divider · md hover-lift · lg sheet · xl palette. All oklch(0.35 0.05 60 / α) — warm, never pure black.

Motion

Hover me — lift −2px, md shadow

Durations 120 / 200 / 320 / 550ms (fast/base/slow/deliberate). Signature ease ease-spring cubic-bezier(0.22,1,0.36,1). Card lift = transition-[transform,box-shadow] duration-base ease-spring. Entrance rhythm 0 / 60 / 120ms. Reduced-motion globally honored.
